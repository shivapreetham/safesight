01

Request path — extension to verdict

extension/*.js · service/app.py · service/cache.py

The content script never scores anything itself — it only finds images, batches their URLs, and later applies a threshold to a score it's given. All fetching and inference happen server-side, keyed by a cache entry that includes the scoring strategy, not just the URL.

extension/content.js → background.js → service/app.py

02

SSRF-hardened fetch

service/fetcher.py

Every redirect hop is re-resolved and re-checked manually — httpx is told follow_redirects=False specifically so the fetcher, not the HTTP client, decides whether the next hop is safe to request at all.

fetch_image() — up to MAX_REDIRECTS = 5 hops 
flowchart TD
    U["URL (from extension batch)"]:::decision --> SCHEME{"scheme is<br/>http or https?"}:::decision
    SCHEME -- no --> R1["FetchError:<br/>unsupported scheme"]:::danger
    SCHEME -- yes --> DNS["_host_is_public()<br/>getaddrinfo, run in worker thread"]:::amber
    DNS --> PUB{"every resolved IP<br/>.is_global?"}:::decision
    PUB -- no --> R2["FetchError:<br/>host not allowed"]:::danger
    PUB -- yes --> REQ["GET, follow_redirects=False"]:::amber
    REQ --> ISR{"response is<br/>a redirect?"}:::decision
    ISR -- "yes, hop ≤ 5" --> SCHEME
    ISR -- "yes, hop > 5" --> R3["FetchError:<br/>too many redirects"]:::danger
    ISR -- no --> CT{"Content-Type<br/>starts with image/?"}:::decision
    CT -- no --> R4["FetchError:<br/>not an image"]:::danger
    CT -- yes --> STREAM["stream body,<br/>abort past fetch_max_bytes (10MB)"]:::store
    STREAM --> SIZE{"min(width,height)<br/>≥ min_image_side (64px)?"}:::decision
    SIZE -- no --> R5["FetchError:<br/>image too small"]:::danger
    SIZE -- yes --> OK["decoded PIL.Image<br/>returned to app.py"]:::success

03

Cascade inference — the asymmetric early exits

ml/strategies.py · ml/inference.py

All five thresholds below are literal constants in ml/strategies.py and the Preset dataclass in ml/inference.py — not rounded or paraphrased. The asymmetry is real: a low full-frame score only exits SAFE when the image is already small enough to be at training scale.

predict_cascade() — 1 to ~365 patches, adaptive 
flowchart TD
    START["image, resize_keep_aspect(690px short side)"]:::decision --> S1["Stage 1 — score_full_frame()<br/>1× 224×224 patch"]:::amber
    S1 --> HI{"score ≥ 0.85?"}:::decision
    HI -- yes --> NSFWX["Exit: NSFW<br/>stages=[full_frame]"]:::danger
    HI -- no --> LO{"score ≤ 0.05 AND<br/>short side ≤ 400px?"}:::decision
    LO -- yes --> SAFEX["Exit: SAFE<br/>stages=[full_frame]"]:::success
    LO -- no --> S2["Stage 2 — predict(preset='fast')<br/>window=265px, stride 0.5, no TTA<br/>~24 patches @ 800×600"]:::amber
    S2 --> BAND{"0.35 < score_large < 0.65?"}:::decision
    BAND -- no --> FASTX["Exit: fast verdict<br/>stages=[full_frame, fast]"]:::success
    BAND -- yes --> S3["Stage 3 — predict(preset='accurate')<br/>windows=[200,265,330]+[140]<br/>flip TTA + fixed crops + soft-NMS<br/>~340 patches @ 800×600"]:::danger
    S3 --> FINALX["Final verdict<br/>stages=[full_frame, fast, accurate]"]:::success

RQSA-MIL — one region through the model

ml/model.py

No ground-truth IoU exists at inference — pseudo_iou=0.5 is a fixed constant fed to every region, not learned or looked up per image.

MLOps loop — scores, drift, feedback, gate

mlops/*.py · .github/workflows/ci.yml

One deliberate gap is drawn in here: the golden-set regression gate exists (ml/eval_golden.py) but is not wired into CI — it runs manually, locally, before a release, because the labeled positive set can't be committed to a public repo.

Nothing below was a large error — SafeSight's docs were mostly accurate going in. These are the claims that didn't survive tracing back to source.

01
